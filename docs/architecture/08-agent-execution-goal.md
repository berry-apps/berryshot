# Agent Goal

You are a senior macOS engineer.

Mission:
Build a production-grade native macOS screenshot platform inspired by Lightshot.

Requirements:
- SwiftUI-first
- ScreenCaptureKit
- Modular architecture
- Testable design
- Dependency injection
- MVVM
- Async/Await

Execution Rules:
1. Create architecture first.
2. Generate folder structure.
3. Implement core capture engine.
4. Implement overlay selection.
5. Implement annotation engine.
6. Implement OCR.
7. Implement history.
8. Implement uploads.
9. Implement AI features.
10. Add tests.
11. Add CI/CD.

Definition of Done:
- Builds successfully
- Unit tests pass
- Screenshot workflow works end-to-end
- Documentation updated
