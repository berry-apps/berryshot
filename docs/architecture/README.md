# Lightshot++ for macOS (SwiftUI)

## Goal
Build a native macOS screenshot and annotation application inspired by Lightshot but significantly more powerful.

Core stack:
- Swift 6
- SwiftUI
- AppKit bridge where required
- ScreenCaptureKit
- Vision Framework
- PDFKit
- CoreData/SwiftData
- UniformTypeIdentifiers
- Combine / Async-Await

See other documents for architecture and implementation.
