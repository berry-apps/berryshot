# Product Requirements

## Core Features
1. Global hotkey capture
2. Region capture
3. Window capture
4. Full screen capture
5. Multi-monitor support
6. Annotation layer
7. Blur tool
8. Pixelate tool
9. OCR extraction
10. Copy image
11. Copy text from OCR
12. Save history
13. Cloud upload
14. Share links
15. Pin screenshot on top
16. Screen color picker
17. Recording support
18. AI actions

## Non Functional
- Launch < 500ms
- Capture latency < 100ms
- Memory efficient
- Offline-first
