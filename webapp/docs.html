Introduction

BerryShot Documentation

BerryShot is a native, source-available macOS utility built with Swift 6.0 that delivers lightning-fast region screen captures (<100ms latency), rich canvas annotations, 100% offline Optical Character Recognition (OCR), automated PII redaction, and multi-provider AI vision integrations directly from your Menu Bar.

ScreenCaptureKit

GPU-accelerated native capture without memory leaks or UI lag.

Privacy First

On-device OCR and Keychain Enclave encryption for all API keys.

AI & MCP Ready

Direct bridge for Claude Code, Codex, Gemini 2.0, and GPT-4o.

Installation & Building From Source

Option 1: Official DMG Release (Recommended)

Download the pre-built universal binary for macOS Sonoma (14.0+) & Sequoia:

https://download-shot.berryhub.app/BerryShot.dmg Download .DMG

Option 2: Build From Source with Swift SPM

# 1. Clone repository

git clone https://github.com/berry-apps/berryshot.git && cd berryshot

# 2. Compile release build

swift build -c release

# 3. Assemble macOS .app bundle

./build_app.sh

# 4. Run your native build

open dist/BerryShot.app

macOS System Permissions

Upon first launch, macOS requires explicit user authorization for screen capture and accessibility features:

1. Screen Recording (Required)

Go to System Settings → Privacy & Security → Screen Recording and toggle on BerryShot. This enables ScreenCaptureKit frame capture.

2. Accessibility (Optional for Auto-Redaction & MCP)

Go to System Settings → Privacy & Security → Accessibility to grant UI inspection permissions for automatic password mask detection and Agent guarded sessions.

Capture Modes & Shortcuts

BerryShot provides multiple capture triggers with instant global hotkey access:

Capture Mode Default Shortcut Description
Region Capture ⌘ ⇧ 2 Interactive crosshair with pixel loupe, coordinates, and aspect ratio lock (hold Shift).
Window Picker ⌘ ⇧ 7 Hover and select any application window with transparent alpha borders or batch capture.
Scrolling Capture ⌘ ⇧ 8 Auto-scrolls document or webpage and stitches into a tall single image.

Live Annotation Tools

Immediately after capturing a region or window, BerryShot renders a floating overlay toolbar featuring:

Geometric Shapes

Draw rectangles, circles, straight lines, and directional arrows with stroke width control.

Numbered Step Badges

Click to stamp ordered step numbers (1, 2, 3...) with customizable badge background colors.

Typography & Highlighting

Rich text overlay with transparent highlighter pens to emphasize key information.

Manual Redaction

Select Gaussian Blur, Mosaic Pixelate, or Solid Cover to mask private regions.

Smart Automated Redaction

BerryShot integrates on-device pattern matching combined with Apple Vision OCR to automatically detect and protect sensitive PII and developer secrets before sharing:

Credit & Debit Cards: Luhn algorithm verification for Visa, MasterCard, Amex.
API Keys & Tokens: OpenAI (`sk-...`), GitHub, AWS Access Keys, Bearer JWTs.
Credentials: Password input fields and masked password strings.
Personal PII: Email addresses, phone numbers, and custom regex terms.
Policy Modes: Under Settings → Privacy, choose between Off, Suggest (shows highlight prompts with 1-click apply), or Required (automatically redacts before copying/saving).

Keychain Enclave Security

All API keys are securely written to the native macOS Keychain. BerryShot communicates directly with official API endpoints via HTTPS with zero intermediate servers.

Local MCP Server (Claude Code & Codex)

BerryShot includes a lightweight stdio executable for the Model Context Protocol located at:

/Applications/BerryShot.app/Contents/Helpers/BerryShotMCP

Quick Setup for Claude Code

claude mcp add berryshot -- /Applications/BerryShot.app/Contents/Helpers/BerryShotMCP

Quick Setup for OpenAI Codex (config.toml)

[mcp_servers.berryshot] command = "/Applications/BerryShot.app/Contents/Helpers/BerryShotMCP" startup_timeout_sec = 10 tool_timeout_sec = 60 required = false

Custom Webhook & Storage API Spec

When configuring custom enterprise upload endpoints under Settings → Cloud, BerryShot transmits binary images as standard multipart form data:

POST /v1/screenshots/upload

Content-Type: multipart/form-data

Authorization: Bearer <YOUR_API_TOKEN>

# Form field:

file: <Screenshot.png>

Set Callback URL Path (e.g., data.url or {json:data.url}) to automatically parse the return JSON and place the link onto your clipboard.

Troubleshooting & FAQ

Q: Screen capture returns a blank or wallpaper-only image?

macOS Screen Recording permission may need to be reset. Open System Settings → Privacy & Security → Screen Recording, remove BerryShot using the minus (-) button, and re-add it.

Q: Is my OCR text or screen capture uploaded anywhere?

No. All OCR runs 100% locally via Apple's Vision framework. Images are only transmitted if you explicitly configure an AI prompt or custom cloud webhook.

Q: How do I report a bug or request a feature?

Please open an issue on the official GitHub Repository.
